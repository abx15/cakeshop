# Contributing to Sweet Cake Shop

Thank you for your interest in contributing to Sweet Cake Shop! We welcome contributions from everyone.

## How to Contribute

1. **Find an Issue**: Look for open issues or create a new one to discuss your ideas.
2. **Fork the Repo**: Fork the repository to your own GitHub account.
3. **Clone the Repo**: Clone your fork to your local machine.
4. **Create a Branch**: Create a new branch for your changes (see Branch Naming below).
5. **Make Changes**: Implement your changes and add tests if applicable.
6. **Commit**: Commit your changes with a clear message (see Commit Guidelines below).
7. **Push**: Push your changes to your fork.
8. **Pull Request**: Open a Pull Request from your branch to our `main` branch.

## Branch Naming

- `feature/your-feature-name` for new features
- `fix/bug-description` for bug fixes
- `docs/what-you-changed` for documentation updates
- `refactor/what-you-refactored` for code refactoring

## Commit Message Guidelines

We follow a simple commit message convention:

- `feat: ...` for new features
- `fix: ...` for bug fixes
- `docs: ...` for documentation
- `style: ...` for formatting, etc.
- `refactor: ...` for code changes that neither fix a bug nor add a feature

Example: `feat: add chocolate cake category`

## Development Setup

1. `npm install`
2. `npm run dev`
3. Fill in necessary environment variables if any.

## Code of Conduct

Please be respectful and professional in all interactions.
